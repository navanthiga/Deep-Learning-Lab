# Experiment 4: Comparative Study of Deep CNN Architectures Using Transfer Learning

This repository contains the Google Colab notebook for **CS3807 -- Deep
Learning Laboratory, Experiment 4**.

The experiment studies transfer learning using a pretrained CNN on the
**CIFAR-10** dataset and compares it with a **LeNet-5 model trained from
scratch**. It also includes model evaluation, CNN architecture
comparison, a lightweight hyperparameter study, and discussion
questions.

## Objectives

-   Prepare and preprocess the CIFAR-10 dataset.
-   Apply transfer learning using a pretrained CNN.
-   Train a new classification head while keeping the pretrained
    backbone frozen.
-   Fine-tune the final layers of the pretrained network.
-   Evaluate the trained model using multiple classification metrics.
-   Visualize performance using training curves and confusion matrices.
-   Compare a transfer-learning model with a LeNet-5 baseline.
-   Study the characteristics of major CNN architectures such as
    LeNet-5, AlexNet, VGG16, GoogleNet, and ResNet50.
-   Perform a lightweight learning-rate and batch-size study.

## Dataset

The experiment uses the **CIFAR-10** dataset.

CIFAR-10 contains:

-   60,000 RGB images
-   Image size: **32 × 32**
-   Number of classes: **10**
-   50,000 training images
-   10,000 test images

The classes are:

``` text
airplane
automobile
bird
cat
deer
dog
frog
horse
ship
truck
```

Pixel values are normalized to `[0, 1]` for visualization and the
LeNet-5 experiment. For transfer learning, the images are resized and
passed through the preprocessing function associated with the selected
pretrained backbone.

## Transfer Learning Models

The notebook supports the following ImageNet-pretrained CNN backbones:

-   VGG16
-   ResNet50
-   MobileNetV2
-   EfficientNetB0

The default configuration in the notebook is:

``` python
MODEL_NAME = "VGG16"
```

The backbone can be changed through the `MODEL_NAME` configuration.

## Transfer Learning Architecture

The pretrained classifier is removed and a new classification head is
attached:

``` text
CIFAR-10 Image
      ↓
Resize to 96 × 96
      ↓
Pretrained CNN Backbone
      ↓
Global Average Pooling
      ↓
Dense Layer (256, ReLU)
      ↓
Dropout (0.3)
      ↓
Dense Layer (10, Softmax)
      ↓
Class Prediction
```

The pretrained convolutional base is initially frozen.

## Training Configuration

## Experiment Workflow

### 1. Dataset Preparation

The CIFAR-10 dataset is loaded using TensorFlow/Keras.

The training data is divided into:

``` text
Training set → 45,000 images
Validation set → 5,000 images
Test set → 10,000 images
```

The test set remains separate for final evaluation.

A sample of CIFAR-10 images is also displayed.

### 2. Feature Extraction

During the first training phase:

-   The pretrained CNN backbone is frozen.
-   Only the newly added classifier head is trained.
-   Adam optimizer is used.
-   The learning rate is `0.001`.

This demonstrates the feature-extraction stage of transfer learning.

### 3. Fine-Tuning

After feature extraction:

-   The pretrained backbone is made trainable.
-   Only the final portion of the backbone is unfrozen.
-   The last **20 layers** are allowed to train by default.
-   The learning rate is reduced by a factor of 100.

The fine-tuning learning rate is therefore:

``` text
0.001 / 100 = 0.00001
```

The purpose is to allow the pretrained features to adapt to CIFAR-10
without making large updates to the pretrained weights.

-   Batch size


## Key Takeaways

This experiment demonstrates the complete transfer-learning workflow:

``` text
Pretrained CNN
      ↓
Freeze Backbone
      ↓
Train New Classification Head
      ↓
Evaluate
      ↓
Unfreeze Final Backbone Layers
      ↓
Fine-Tune with Small Learning Rate
      ↓
Final Test Evaluation
```

It also provides a practical comparison between **training a CNN from
scratch** and **reusing pretrained visual features**, while introducing
important CNN architectures and hyperparameter considerations.
