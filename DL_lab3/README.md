# CNN Image Classification using CIFAR-10

## Deep Learning Laboratory Experiment 3

This project implements and evaluates a **Convolutional Neural Network (CNN)** for multi-class image classification using the **CIFAR-10 dataset**.

The experiment explores the fundamental components of CNNs, including convolution, kernel size, stride, padding, pooling, feature maps, model training, and performance evaluation.

---

## 📌 Objectives

The main objectives of this experiment are:

- Understand the structure and working of Convolutional Neural Networks.
- Load and preprocess the CIFAR-10 image dataset.
- Study the effect of different convolution kernel sizes.
- Analyze the impact of stride and padding on feature map dimensions.
- Visualize feature maps generated by convolution layers.
- Compare Max Pooling and Average Pooling.
- Build and train a CNN for image classification.
- Evaluate the model using Accuracy, Precision, Recall, and F1-score.
- Analyze classification performance using a Confusion Matrix.
- Study the effect of increasing the number of convolution filters.

### 2. Convolution Kernel Size Comparison

The experiment compares different kernel sizes:

- 3 × 3
- 5 × 5
- 7 × 7

Using `valid` padding and stride = 1.

The output feature map size is calculated using:

```text
Output Size = (N - F + 2P) / S + 1
```

Where:

- `N` = Input size
- `F` = Filter size
- `P` = Padding
- `S` = Stride

Larger kernels capture a larger receptive field but require more computation and parameters.

---

## 🏗️ CNN Architecture

The main CNN uses the following architecture:

```text
Input Image
     │
     ▼
Conv2D (32 filters, 3×3, ReLU)
     │
     ▼
Max Pooling (2×2)
     │
     ▼
Conv2D (64 filters, 3×3, ReLU)
     │
     ▼
Max Pooling (2×2)
     │
     ▼
Flatten
     │
     ▼
Dense (128, ReLU)
     │
     ▼
Dense (10, Softmax)
```

### Model Configuration

- Optimizer: **Adam**
- Loss Function: **Sparse Categorical Crossentropy**
- Batch Size: **32**
- Epochs: **20**

## 🔑 Key Learnings

- CNNs use local connectivity and weight sharing to efficiently process images.
- Kernel size affects the receptive field and computational complexity.
- Stride controls how quickly spatial dimensions are reduced.
- Padding helps control feature map dimensions.
- Pooling reduces spatial dimensions and computational cost.
- Max Pooling and Average Pooling can produce different classification performance.
- CNN filters learn hierarchical image features during training.
- Increasing the number of filters can improve representation learning but increases computational cost.
- Accuracy alone is not sufficient for evaluating classification models, making Precision, Recall, F1-score, and Confusion Matrices important evaluation tools.
